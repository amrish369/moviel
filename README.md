# 📖 Overview

Moviel is a modern entertainment platform built with **React, TypeScript, Vite, Tailwind CSS, shadcn/ui, and Supabase**.

Instead of showing only movie lists, the platform combines multiple entertainment experiences into a single application including:

- Movie discovery
- Actor spotlight
- Movie details
- OTT releases
- Music
- Reviews
- Release calendar
- Infinite content feed
- Telegram integration
- User authentication
- Responsive design

The application focuses on performance, usability, and clean UI while maintaining a scalable architecture.

```bash

```

Go to project directory

```bash

```

Install dependencies


```bash

```

# ⚙️ Environment Variables

Create a `.env` file in the root directory.

```env
VITE_SUPABASE_URL=your_supabase_url

VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

If your project uses TMDB or any external API, also configure:

```env
VITE_TMDB_API_KEY=your_api_key
```

Never commit your `.env` file.
